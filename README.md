# EPUB Maker (Offline-first)

โปรเจกต์เริ่มต้นสำหรับนำ EPUB Maker ไปใช้เป็นเว็บแอปติดตั้งได้ (PWA) และ Android APK

## ฟีเจอร์ในเวอร์ชันนี้
- แบ่งหน้าในบทเดิมด้วยปุ่ม “↧ ขึ้นหน้าใหม่” (ไม่สร้างบทใหม่)
- บันทึกอัตโนมัติในเบราว์เซอร์
- ส่งออก/นำเข้าไฟล์โปรเจกต์ `.epubmaker.json` เพื่อสำรองและย้ายเครื่อง
- ใช้ JSZip ที่ติดตั้งในโปรเจกต์ ไม่โหลดจาก CDN
- PWA cache ไฟล์หลักเพื่อเปิดซ้ำแบบออฟไลน์

## ทดสอบเว็บแอป
```bash
npm install
npm run build:web
```
จากนั้นเปิดโฟลเดอร์ `www` ผ่านเว็บเซิร์ฟเวอร์ในเครื่องหรือโฮสต์แบบ HTTPS (Service Worker ใช้กับ `file://` ไม่ได้)

## สร้าง APK ผ่าน GitHub Actions
1. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ใช้ branch `main`
3. เปิดแท็บ Actions แล้วเลือก workflow `Build Android APK`
4. กด `Run workflow`
5. เมื่อเสร็จ ดาวน์โหลด `epub-maker-debug-apk` จากส่วน Artifacts

APK ที่ workflow สร้างเป็น **debug APK สำหรับทดสอบ** ไม่ใช่ไฟล์ release ที่ลงนามเพื่อเผยแพร่ใน Store

## ข้อควรรู้เรื่องข้อมูล
- Autosave เก็บข้อมูลไว้ในพื้นที่ของเบราว์เซอร์/แอปเครื่องนั้น ไม่ได้ซิงก์ข้ามอุปกรณ์
- ควรกด “บันทึกโปรเจกต์” เป็นระยะ และเก็บไฟล์ `.epubmaker.json` ไว้ในที่ปลอดภัย
- หากล้างข้อมูลแอปหรือถอนการติดตั้ง ข้อมูล LocalStorage อาจหายได้
- การเปิดใช้งานออฟไลน์ครั้งแรกต้องเปิดแอปขณะออนไลน์อย่างน้อยหนึ่งครั้งเพื่อให้ Service Worker เก็บไฟล์
